# Emberdeep

Emberdeep is a web prototype for a lightweight cooperative, dice-driven dungeon crawler.

## Current Prototype

- Vite, TypeScript, and Phaser
- 10x8 cave combat room
- Four selectable MVP heroes
- AP-based movement and attacks
- d20 hit resolution and damage dice
- Simple goblin enemy AI
- DOM HUD for hero status, actions, and combat logs

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173/`.

## Verify

```bash
npm test -- --run
npm run build
```
